## 🌟 Key Features (Microsoft Excel 2026 Updates)

1. **Copilot in Excel (July 2026 Edition)**:
   - Frontier AI Model Switcher: **OpenAI GPT-5.6**, **Anthropic Claude Opus 5**, **Google Gemini 2.5 Pro**, **Microsoft Copilot Enterprise**
   - Natural Language Formula Generation (Sinhala & English queries like *"Column B and C sum karanna"*, *"Calculate 15% VAT"*, *"Find highest value"*)
   - Instant Executive AI Insights & Data Trend Analysis
   - Corporate Brand Themes (One-tap brand styling for tables and headers)

2. **Interactive Checkboxes in Cells**:
   - Modern Checkbox feature: Tap to toggle `TRUE`/`FALSE` with dynamic reactive recalculation of dependent formulas!

3. **2026 Regex Functions**:
   - `=REGEXTEST(text, pattern)`
   - `=REGEXEXTRACT(text, pattern)`
   - `=REGEXREPLACE(text, pattern, replacement)`

4. **Python in Excel (`=PY(...)`)**:
   - Run Python list aggregations and data computations directly in cells.

5. **Modern Lookup & Dynamic Arrays**:
   - `XLOOKUP`, `VLOOKUP`, `SORT`, `UNIQUE`, `SEQUENCE`
   - Classic functions: `SUM`, `AVERAGE`, `COUNT`, `COUNTA`, `MAX`, `MIN`, `ROUND`, `PRODUCT`, `POWER`, `SQRT`, `IF`, `IFS`, `AND`, `OR`, `NOT`, `CONCAT`, `UPPER`, `LOWER`, `LEN`, `TRIM`, `TODAY`, `NOW`

6. **Page Setup & Print Options**:
   - Direct WiFi/System Printing
   - Export to high-resolution PDF document (A4, Letter, Legal) with Portrait/Landscape orientation & gridlines control
   - Share PDF via WhatsApp, Gmail, Telegram
   - Export & Share CSV

7. **Cloud Authentication & Sync**:
   - **Microsoft 365 / Outlook** Sign-in with OneDrive sync
   - **Google / Gmail** Sign-in with Google Drive sync
   - Offline Guest Mode (works 100% without internet connection)

8. **Google Play Store Ready**:
   - Package Name: `com.greensoft.greenexcel`
   - Android 14 (Target SDK 34) & Min SDK 21
   - High-resolution 512x512 Store icon & full density launcher icons (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi)
   - Built-in Privacy Policy and Play Store compliance dialog
   - Builds both **Release APK** (`app-release.apk`) and **Google Play Bundle** (`app-release.aab`)!

## 🚀 How to Build APK via GitHub Actions (පෙර පරිදිම GitHub හරහා APK එක Build කරගන්නේ මෙහෙමයි)

1. **Git Repository එක Initialize කර GitHub එකට Push කරන්න**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Green Excel 2026 Pro"
   git branch -M main
   git remote add origin https://github.com/GreenSoftSachi/green-excel.git
   git push -u origin main
   ```
   *(GitHub එකේ `green-excel` නමින් අලුත් repository එකක් සාදා ඉහත command එක run කරන්න).*

2. **GitHub Actions මඟින් Build එක Run වීම**:
   - ඔබ Push කළ පසු GitHub Repository එකේ **Actions** tab එකට යන්න.
   - **"Build Green Excel APK & Play Store Bundle"** workflow එක ස්වයංක්‍රීයව run වේ (විනාඩි 3-5ක් පමණ ගතවේ).

3. **APK එක Download කරගන්න**:
   - Build එක Complete වූ පසු (කොළ පාට හරි ලකුණ වැටුණු පසු), Actions run එක click කරන්න.
   - පිටුවේ පහළින් ඇති **Artifacts** කොටසෙන්:
     - 📱 **Green-Excel-Release-APK** (Phone එකට කෙලින්ම Install කිරීමට)
     - 📦 **Green-Excel-PlayStore-AAB** (Google Play Store එකට Upload කිරීමට)
     Download කරගත හැක!
